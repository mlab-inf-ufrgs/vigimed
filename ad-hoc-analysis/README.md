# Análises ad hoc do VigiMed

Estudos específicos que consomem a camada Gold existente. Cada estudo mantém seu código, testes, metodologia e instruções de reprodução em um diretório próprio.

| Estudo | Objetivo |
| --- | --- |
| [Dipirona, 2019–2025](dipirona/README.md) | Base descritiva de notificações com dipirona suspeita e suas associações para TCC de Farmácia. |

Os dados de entrada permanecem em `data/03_gold/`. Resultados individuais, arquivos para Excel e pacotes de entrega são gerados localmente e ficam fora do Git. Metodologia e manifesto permitem identificar a extração utilizada.

O código é mantido no próprio VigiMed. Uma branch e um pull request permitem revisar a análise antes de integrá-la ao projeto; um fork é uma alternativa para colaboradores sem permissão de escrita.
