# Pull request template

Use este formato ao abrir PRs no VigiMed (cole no corpo do PR no GitHub).

```markdown
## 🚀 Summary
<!-- 1–3 frases: o que muda e por quê -->

## 📂 Affected Components
- [ ] `docs/` —
- [ ] `src/` —
- [ ] `eda/` —
- [ ] `tests/` —
- [ ] `data/` —
- [ ] `other` —

## 🔍 Changes
- ✅ **What was added?**
- 🔧 **What was changed?**
- ❌ **What was removed?**

## 📊 Validation & Testing
- [ ] Manual —
- [ ] Automated —
- [ ] No new tests needed

## 📝 Notes for Reviewers
<!-- Riscos, follow-ups, links de PRs relacionadas, paths legados, LFS, etc. -->
```
